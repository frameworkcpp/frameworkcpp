# Documentation

This documentation is written for humans first. Each page explains the idea
behind a piece of the framework and then how to use it — it is not a dump of
type signatures.

## How it is organised

FrameworkCpp is modular, and so is the documentation. Each module gets a section
in the menu, and inside a section you read top to bottom: first the idea, then
the pieces, then the details.

These are the modules with pages today; the framework is more than this list,
and it keeps growing.

| Module | Status | Section |
| --- | --- | --- |
| Memory | documented | [Memory](/memory/) |
| Environment | documented | [Environment](/environment/) |
| More | planned | — |

## Writing a page

Anyone can contribute a page. The [Writing Documentation](/contribute/documentation)
guide explains the style the pages follow — start from the reader's problem,
one idea per section, show a runnable example, explain the *why* — and how to
preview the site locally.
