# Documentation

This documentation is written for humans first. It explains how each piece of
the framework works and how to use it — it is not a dump of type signatures.
Technical names appear in the text and code where they belong, and the menu
keeps the concepts.

## How it is organised

FrameworkCpp is modular, and so is the documentation. Each module gets a
section in the menu, and inside a section you read top to bottom: first the
idea, then the pieces, then the details.

| Module | Status | Section |
| --- | --- | --- |
| Memory Management | documented | [Memory Management](/memory-management/) |
| Environment Management | documented | [Environment Management](/environment/) |
| More | planned | — |
